Access Suspense Items
in Applied Epic

Locate and assign premium payable items held in suspense. This guide walks through the navigation steps required to filter, search, and process suspended transactions for specific carriers — using Safeco as the working example.

3 Phases
10 Steps
~5 Minutes

Interface Management

What This Guide Covers

Suspense items are downloaded transactions that Epic cannot automatically match to an existing policy. They sit in Interface Management → Assign Items in Suspense until a user reviews and assigns them. This guide covers how to navigate to the suspense queue, filter by carrier, and locate the records that need attention. The example uses Safeco — substitute your carrier's PPE name in the search criteria field for any other carrier.

Initial Navigation ↓ Suspense Queue ↓ Filter & Search ↓
Phase 01 Initial Navigation
1
Start on the Epic Home page
Log in to Applied Epic and confirm you are on the main Home page before proceeding. All navigation in this workflow begins from the Home menu.
2
Navigate to Procedures via the Home menu dropdown
Click the Home menu in the top navigation bar, then select Procedures from the dropdown. This opens the Procedures workspace where Interface Management tools are located.
Phase 02 Accessing Suspense Items
3
Click "Interface Management" in the left navigation menu
In the Procedures workspace, locate the left-hand navigation panel and select Interface Management to expand its options.
4
Click "Assign Items in Suspense"
Under Interface Management, click Assign Items in Suspense. This opens the suspense assignment screen where unmatched download transactions are queued for review.
5
Select "Policies" from the list
In the Assign Items in Suspense screen, select Policies from the available list. This scopes the suspense queue to policy-level download transactions.
Note: Other options such as Claims may appear in the list. Selecting Policies ensures you are working only with premium payable and policy download items.
6
Click "Run"
Click the Run button to load the full suspense queue. All unmatched policy downloads will populate in the results panel.
Heads up: Running without a filter first will return all suspense items across all carriers. If the queue is large, proceed to Phase 03 to filter before reviewing.
Phase 03 Filtering and Searching
7
Select "Premium Payable" from the "Search where" dropdown
In the search/filter bar above the results, open the Search where dropdown and select Premium Payable. This targets the filter to the premium payable field on each suspense record.
8
Type the Carrier PPE Name into the search criteria field
In the search criteria input, type the carrier's PPE name exactly as it appears in Epic. In this example, the search term is Safeco.
Carrier naming: The PPE name must match Epic's internal carrier name exactly — partial matches may return incomplete results. If unsure of the exact name, check the IVANS Connections Download Guide for your carrier list.
9
Click "Find" to execute the search
Click the Find button to run the filtered search. Epic will return only the suspense items where the Premium Payable field matches the carrier name you entered.
10
Review the filtered results — workflow complete
The results panel now shows only the suspense items for the selected carrier (e.g., Safeco downloads). From here, select individual records to review, assign, or process each suspended transaction.
Tip: Repeat the filter step with a different carrier PPE name to work through suspense items from multiple carriers without re-running the full queue each time.
Common Questions
What does it mean when an item is "in suspense"? ▾

A suspense item is a downloaded transaction from a carrier that Applied Epic could not automatically match to an existing policy record. This typically happens when the policy number format doesn't align with what's in Epic, the policy doesn't exist yet in the system, or there's a mismatch in carrier identifiers. The item sits in the suspense queue until a user manually reviews it and assigns it to the correct policy or contact.

Why filter by "Premium Payable" specifically? ▾

The Premium Payable field identifies the carrier associated with each suspense record. Filtering by this field allows you to isolate all suspense items tied to a single carrier in one view, rather than scrolling through a mixed queue from every carrier that sends downloads. It is the most efficient way to batch-process suspense items by carrier when your queue contains transactions from multiple sources.

What if the carrier name doesn't return any results? ▾

If your search returns no results, the most likely cause is a naming mismatch. The PPE name in the search field must match exactly how the carrier is labeled in Epic's interface — abbreviations, punctuation, and spacing all matter. Try searching with a shorter portion of the name (e.g., "Saf" instead of "Safeco") to see if partial matches appear, then refine from there. You can also cross-reference the IVANS Connections Download Guide for the carrier's exact Epic label.

How often should the suspense queue be reviewed? ▾

Best practice is to review the suspense queue daily, ideally as part of a morning download processing routine. Items left in suspense for extended periods can cause discrepancies between carrier records and what's reflected in Epic — particularly for endorsements, cancellations, and reinstatements. Unprocessed suspense items can also create billing and commission tracking gaps if premium payable records are not assigned to the correct policies promptly.
