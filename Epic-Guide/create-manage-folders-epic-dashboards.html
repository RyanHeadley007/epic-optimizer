Scenario

Your Applied Epic Dashboard has grown with multiple panels spread across a single view — renewals, suspense counts, AR aging, and more — making it hard to navigate quickly. This workflow shows you how to create folders inside the Dashboard to group related panels together, rename them, and reorder them so your workspace stays organized as it scales.

Phase 01 Open Dashboard Settings
1
Navigate to the Dashboards module
From the Epic home screen, click the Dashboards icon in the left-hand navigation rail or select it from the top menu bar. Your current dashboard view will load.
2
Click the gear / settings icon
Locate the settings (gear) icon at the top-right of the Dashboard panel area and click it to open the Dashboard configuration options.
Tip: If you don't see the gear icon, make sure you're viewing a dashboard you own or have edit rights to. Shared read-only dashboards won't expose configuration controls.
3
Select "Manage Folders" from the settings menu
From the dropdown that appears, choose Manage Folders (or the equivalent folder management option). This opens the folder management panel where you can view, create, and edit folders.
Phase 02 Create a New Folder
4
Click the "Add Folder" or "+" button
In the folder management panel, locate the Add Folder button (often shown as a "+" or labeled explicitly) and click it. A new folder entry will appear in the list, ready for naming.
5
Enter a name for the folder
Type a descriptive name into the folder name field — for example, Renewals, AR & Billing, or Suspense Queue. Keep names short so they display cleanly in the dashboard navigation.
Tip: Use consistent naming conventions across folders if multiple team members share the same dashboard configuration. This prevents confusion when folders are later edited by someone else.
6
Save or confirm the new folder
Press Enter or click the checkmark / Save button to confirm the folder name. The new folder will appear in the folder list and become available as a destination for your dashboard panels.
Phase 03 Assign Panels to the Folder
7
Open the panel's individual settings
Return to the main dashboard view. Hover over or click into the panel you want to move into the folder, then click the panel's own gear or edit icon to open its settings.
8
Locate the "Folder" assignment field
In the panel settings, find the Folder dropdown or field. This is where you assign which folder this panel belongs to. It may default to "None" or "Unassigned" if no folder has been set.
9
Select the target folder from the dropdown
Click the dropdown and choose the folder you just created. The panel will be associated with that folder once you save.
Note: A panel can only belong to one folder at a time. If you reassign it to a different folder later, it will be removed from the previous one automatically.
10
Save the panel settings
Click Save or OK to confirm the panel's folder assignment. Repeat steps 7–10 for each additional panel you want to move into the folder.
Phase 04 Rename or Delete a Folder
11
Return to Manage Folders
Click the gear icon on the dashboard again and select Manage Folders to reopen the folder management panel. Your existing folders will be listed.
12
Click the edit (pencil) icon next to the folder name
To rename a folder, click the pencil or edit icon beside the folder. The name field becomes editable — clear it and type the new name, then press Enter or Save to confirm.
13
Delete a folder using the trash / remove icon
To remove a folder, click the trash or remove icon beside it. Confirm the deletion in the prompt that appears.
Important: Deleting a folder does not delete the panels inside it — those panels will revert to "Unassigned" and remain accessible on the dashboard. The folder structure is just an organizational layer.
14
Reorder folders using drag-and-drop
If the folder management panel supports drag-and-drop reordering, grab the handle icon (usually three horizontal lines) to the left of a folder name and drag it to the desired position in the list. The order here controls the display order in the dashboard navigation.
Tip: Put your highest-priority folder (e.g., the one you open first every morning) at the top of the list so it renders first in the dashboard tab bar.
15
Close the folder management panel and confirm layout
Click Done or close the panel. Your dashboard should now display the folder tabs or navigation labels at the top or side of the panel area. Click each folder tab to verify the correct panels are grouped within it.
Common Questions
Can other users see the folders I create? ▾

It depends on whether your dashboard is a personal or shared dashboard. Personal dashboards and their folder structures are visible only to you. If you're working on a shared team dashboard, other users with access will see the same folder layout — and changes you make may affect their view. Confirm with your administrator before restructuring a shared dashboard.

What happens to panels that aren't assigned to a folder? ▾

Unassigned panels will typically appear in a default "root" view or under an "All" tab, depending on how your dashboard is configured. They remain fully functional — they just won't be grouped under any folder label.

Is there a limit to how many folders I can create? ▾

Applied Epic does not publish a hard limit on the number of dashboard folders, but practical usability tends to cap out around 6–10 folders before navigation becomes unwieldy. Focus on logical groupings rather than creating a folder for every single panel.

Can I nest folders inside other folders? ▾

No — Applied Epic's dashboard folder system is a single-level structure. You can create multiple sibling folders, but you cannot nest one folder inside another. If you need sub-grouping, consider using panel naming conventions (e.g., "AR — Aging 30 Days", "AR — Aging 60 Days") to create a logical hierarchy within a single folder.
