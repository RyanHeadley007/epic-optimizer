Scenario

You need to locate and work through suspended download transactions for a specific carrier — for example, Safeco premium payable items. Rather than scrolling through an unfiltered suspense queue, this workflow shows you how to navigate directly to Interface Management, filter the list to Premium Payable items, and search by carrier name so only the relevant transactions are displayed.

You need to locate and work through suspended download transactions for a specific carrier — for example, Safeco premium payable items. Rather than scrolling through an unfiltered suspense queue, this workflow shows you how to navigate directly to Interface Management, filter the list to Premium Payable items, and search by carrier name so only the relevant transactions are displayed.

Phase 01 Initial Navigation
1
Start on the Epic Home page.
Ensure you are logged in and viewing the main Epic Home dashboard before beginning this workflow.
2
Navigate to Procedures via the Home menu dropdown.
Click the Home menu in the top navigation bar and select Procedures from the dropdown list that appears.
Phase 02 Accessing Suspense Items
3
Click Interface Management in the left navigation menu.
Find and select Interface Management in the left-hand sidebar of the Procedures section.
4
Click Assign Items in Suspense.
Select this option from the Interface Management panel to open the suspense queue.
5
Select Policies from the list.
Choose Policies as the item type you want to work with from the available options in the suspense queue.
6
Click Run.
Execute the query to load all suspense items in the Policies queue before applying filters.
Phase 03 Filtering and Searching
7
Select Premium Payable from the Search where dropdown.
Use the Search where dropdown to narrow the results to premium payable items only, excluding other transaction types from the queue.
8
Type the carrier's PPE name into the search criteria field.
Enter the carrier name exactly as it appears in your carrier setup. In this example, the carrier is Safeco.
Tip: Use the exact PPE name as configured in your carrier setup. A partial name may return incomplete results or no results at all.
9
Click Find to execute the search.
Run the search to display all matching premium payable suspense transactions for the specified carrier.
10
Review the filtered results — you are now isolated to the carrier's downloads.
The suspense queue now displays only premium payable transactions for the carrier you searched. From here you can select individual items to review, assign, or troubleshoot.
Workflow complete. You are now filtered to the carrier's suspense downloads and ready to begin assigning or resolving individual transactions.
