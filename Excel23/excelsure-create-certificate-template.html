Before You Begin

Certificate templates in CSR24 drive consistency across every certificate your team issues. Build one template per certificate type — ACORD 25 for liability, ACORD 28 for property — and keep coverage descriptions aligned with the actual policy language. Templates created here will be available to all users issuing certificates for this client.

Phase 01 Set Up the Template
1
Navigate to the client's certificate section in CSR24
Log into CSR24 and open the client account for which you are creating the template. Go to the Certificates section and locate the Templates area — this is separate from the individual certificate issuance screen.
2
Select "New Template" and choose the certificate form
Click New Template to open the template builder. Select the appropriate ACORD form for this template. Common options include:
  • ACORD 25 — Certificate of Liability Insurance (most common)
  • ACORD 28 — Evidence of Commercial Property Insurance
  • ACORD 27 — Evidence of Property Insurance (personal lines)
Form selection is permanent: You cannot change the ACORD form after the template is saved. If you select the wrong form, you must delete the template and start over.
3
Name the template clearly
Give the template a name that identifies the coverage type and any special conditions — for example "GL + Auto — Standard" or "ACORD 25 — Additional Insured — Blanket." A clear naming convention saves time when staff are selecting templates during certificate issuance.
Naming convention: Include the form type, primary coverage line, and any key endorsement or wording variation in the name. Avoid generic names like "Template 1" that become meaningless over time.
Phase 02 Configure Coverage Lines & Language
4
Add and configure each coverage line
For each line of coverage the client carries, add a coverage row to the template. Set the coverage type, policy number merge field, and limit fields. CSR24 will pull live policy data when the certificate is generated — use merge fields where available rather than hard-coding limits.
Tip: Only include coverage lines the client actually has. Leaving blank or "N/A" rows on a certificate can create confusion for certificate holders and may trigger compliance questions.
5
Enter the Description of Operations language
The Description of Operations field (Box 17 on ACORD 25) is where additional insured wording, waiver of subrogation language, and project-specific notes appear. Enter the standard wording for this template type. Common inclusions:
  • Additional insured status and the applicable endorsement form number
  • Waiver of subrogation wording if endorsed on the policy
  • Primary and non-contributory language if required
  • Notice of cancellation provisions exceeding the policy's standard terms
Legal accuracy matters: The Description of Operations must reflect what is actually endorsed on the policy. Do not add additional insured language if no AI endorsement exists on the policy — this creates a certificate that misrepresents the coverage.
6
Set the producer information and signatory
Confirm the producer name, address, and contact information are populated correctly in the template. Set the authorized representative field to the appropriate signatory for Excelsure. This information will appear on every certificate generated from this template.
Phase 03 Save & Test the Template
7
Save the template
Once all coverage lines, description language, and producer information are complete, save the template. CSR24 will confirm the save and the template will become available for selection during certificate issuance for this client.
8
Generate a test certificate to verify the output
Issue a test certificate using the new template and review the PDF output carefully before putting the template into production use. Check that all coverage lines populated correctly, limits appear as expected, and the Description of Operations wording is accurate and complete.
Test checklist: Verify the named insured matches the policy, policy numbers are correct, effective and expiration dates are accurate, and no coverage lines appear blank or show placeholder text.
Do not distribute the test certificate. Delete or void it after reviewing. Only issue certificates to holders after you have confirmed the template output is accurate.
Common Questions
Can the same template be used for multiple clients?▼

Templates in CSR24 are created within a specific client account and are tied to that client's policy data via merge fields. You cannot share a single template across multiple clients. However, you can use a well-configured template as a reference and replicate its structure when creating templates for other clients with similar coverage profiles.

What if the client's coverage changes after the template is built?▼

If policy limits or coverage types change, update the template to reflect the new policy data. Merge fields tied to the policy will pull updated data automatically, but static text — especially in the Description of Operations — must be reviewed and manually updated to ensure the wording still accurately reflects the endorsed coverages.

Who can access and edit templates in CSR24?▼

Template access in CSR24 is governed by user permission levels set by your CSR24 administrator. Typically, all licensed staff can use templates to issue certificates, but creating and editing templates may be restricted to senior staff or administrators. Check with your CSR24 admin if you do not see the New Template option.
