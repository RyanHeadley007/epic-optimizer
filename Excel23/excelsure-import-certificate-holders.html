Import Certificate Holders
into CSR24

How to import a bulk holder list into CSR24 using the approved Epic Optimizer import template. Covers file selection, template assignment, default settings, and post-import verification.

3 Phases
12 Steps
CSR24

← Back to Excelsure Guide Library
Required Before You Start

You must use the approved Excel import template that has been mapped specifically to CSR24 import fields. Do not use a custom spreadsheet — field mapping will fail. Download the Holder Import Template (v1.1) →

Phase 01 Navigate to the Import Screen
1
Start from the account details page in CSR24
Open CSR24 and navigate to the client's account details page. This is your starting point for the import workflow.
2
Click "Holders"
From the account details page, click the Holders tab to open the certificate holders list for this account.
3
Click "Import"
Inside the Holders section, click the Import button to open the import dialog.
Phase 02 Configure the Import
4
Click "Choose File" and navigate to the saved Epic file
Click Choose File and navigate to the holder list file that was exported from Epic. Select the file to load it into the import dialog.
5
Select the appropriate template to add the holders to
Choose the certificate template you want to associate these holders with. Click the template row to select it.
Verify your selection: When you select a template, the row will turn blue — this confirms the template is selected and you are ready to proceed. If no row is highlighted blue, nothing is assigned.
6
Check "Default Send Email/Fax to Yes"
Check the Default Send Email/Fax to Yes checkbox. This sets all imported holders to receive certificates via email or fax when certificates are issued.
7
Check "Default Send Renewed Cert to Yes"
Check the Default Send Renewed Cert to Yes checkbox. This flags all imported holders to automatically receive renewal certificates when the policy renews.
8
Check "Default Lock Holder Info on Self-Service to Yes"
Check the Default Lock Holder Info on Self-Service to Yes checkbox. This prevents self-service portal users from modifying the imported holder information.
9
Click "Import"
With the file selected, the template row highlighted blue, and all three checkboxes checked, click the Import button to run the import.
Phase 03 Verify the Results
10
Review the results page
CSR24 will redirect you to a results page. Look for any discrepancies between Total Records and Records Inserted — these numbers should match.
If the counts don't match: Rows that failed to import will be listed on this page. Correct those entries in your spreadsheet and re-run the import for the failed records only — do not re-import the full list or you will create duplicates.
11
Click "Holders"
Navigate back to the Holders tab to view the full list of certificate holders now associated with this account.
12
Verify all holders have been uploaded
Confirm the total holder count in the list matches the number of records in your source file. Spot-check a few entries to verify names and contact details imported correctly.
Workflow complete. All holders are now linked to the selected certificate template with the correct default send and lock settings applied.
Common Questions
Where do I get the approved import template?▼

The approved Holder Import Template (v1.1) is linked at the top of this guide. It is also available in the Epic Optimizer GitHub repository. You must use this template — do not build your own spreadsheet, as the column headers must match CSR24's import field mapping exactly.

How do I confirm the correct template is selected in step 5?▼

When you click a template in the selection list, the row turns blue. That blue highlight is the only confirmation that a template has been assigned. If the row does not turn blue, click it again. Do not proceed past step 5 without a blue-highlighted row — holders imported without a template selection will not be linked to any certificate.

Total Records and Records Inserted don't match — what do I do?▼

CSR24 skips rows with missing or invalid data in required fields. On the results page, identify the failed rows, correct those specific entries in your source spreadsheet, and re-run the import with only those corrected rows. Never re-import the full file after a partial success — it will create duplicate holders for all the rows that already imported correctly.
